## 极简安装（安装即用）

本插件已实现 **Zero-Config（零配置）**，安装后自动完成所有环境配置。

1. **下载插件**：获取 `wf-dialog-mcp-x.x.x.vsix` 文件。
2. **安装插件**：
   - 打开 Windsurf / Cursor
   - 将 `.vsix` 文件直接拖入扩展栏，或通过 "Install from VSIX" 安装。
3. **重启 IDE**：重启后插件自动启动，无需手动修改任何 JSON 配置文件。
